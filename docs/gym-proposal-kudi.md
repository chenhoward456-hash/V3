> 提案人：Howard（北屯店主管）
> 受文者：酷地健身 老闆 / 總經理
> 日期：2026-06-02

---

## TL;DR

北屯被連鎖打邊緣化、被總部資源傾斜西屯。**正面打不贏，繞道**：用我們已有的運動醫學背景 + 客戶數據系統，**做西屯做不來的事 — 高端健康管理**。

**對酷地**：北屯多一條 ARPU 5-10× 的收入線、不用對連鎖打價格戰、自然客單價拉升。
**對我**：系統授權費 + 新會員抽成 = 互利。

預估北屯 Q3 試行 → 月增 NT$80k-150k 淨收入（健身房端）。

**連鎖打不到、傳統 PT 接不住** — 我們的位置。

## 3. 提案：酷地北屯「健康管理會員制」

**不取代現有 PT**，是 PT 上面再加一層「**數據驅動健康管理**」。

|---|---|---|---|
| **基本會員** | 1,500 | 場地 + 自助訓練 | 既有市場（保留）|
| **PT 課程** | 1,500-1,750/堂 | 1on1 教學 | 既有市場（保留）|

## 4. 商業模式：酷地 + Howard 互利

### 客戶端定價（以 Longevity Pro 18,000/月為例）

```
客戶月費 18,000
   ↓ 拆分
教練分潤（4 堂 PT + LINE 諮詢）  6,000  (33%)
健身房分潤（場地 + 行政 + 行銷）  6,000  (33%)
血檢供應商                       3,000  (17%)
平台費（Howard 系統授權+營運）    3,000  (17%)
```

### Howard 拿什麼

| 項目 | 金額 |
|---|---|
| **一次性系統授權**（給酷地三間店）| NT$ 300,000 |
| **每月平台費**（含 hosting / AI / 維護）| NT$ 15,000 起，按客戶數調整 |
| **新方案抽成**（自主追蹤、教練全方位、Longevity Pro 業績）| 8-10% |
| **不影響**現有 PT 課收入分潤（教練照拿）| - |

### 預估北屯 Q3 試行 ROI（保守估）

```
試行目標：200 會員中 10% 轉新方案 = 20 人
平均月費 8,000（保守取教練全方位中位數）
新方案月營收 = 20 × 8,000 = NT$ 160,000

拆分：
教練分 33% → 53,000/月  ← 教練被動加薪
健身房分 33% → 53,000/月  ← 老闆新收入線
血檢 17% → 27,000/月
平台 17% → 27,000/月（給 Howard）

→ Howard 平台費（含開發抽成）約 NT$25,000-30,000/月
→ 健身房淨新收入 NT$53,000/月（純加，沒佔原本資源）
→ 教練每人多分 NT$6,000/月（按參與度）
```

**3 個月內**：若達 20 人，年化新增 600k+ 淨收入給北屯。
**6 個月內**：若達 50 人 + Longevity Pro 10 人，年化新增 1.5M+。

## 5. 實施路徑

### Phase 1：北屯試行（2026 Q3，3 個月）

1. **教練培訓**（2 週）— 8 位教練學會用 admin 介面 review 學員
2. **行銷上架**（2 週）— FB / IG / 店內海報，鎖 40+ 男性
3. **10 個種子客戶**轉入（從現有 PT 高客單）
4. **AI Agent 對教練端開放**（已開發完成，免成本）
5. **月度檢討**：retention、ARPU、教練滿意度

**成功指標**（Q3 末）：
- ✅ 20 個新方案客戶
- ✅ 教練每月多領 5,000+
- ✅ 健身房月增 50k+ 收入

### Phase 2：複製到西屯 / 第三店（2026 Q4）

- 三店共用系統（已支援多店）

### Phase 3：擴張（2027）
